# Vibe Engineering for Codex

This adapter exposes the repository's canonical Vibe Engineering skills and commands to Codex. It does not copy or redefine the process.

Start at the repository `AGENTS.md`, hydrate the target project's ICM workspace, and use `node scripts/factory-control.mjs status <workspace>` to discover the next legal action. A build cannot advance without exact-revision Open Code Review evidence, a cold ICM walk receipt, independent review, and a Judge SHIP verdict. Production always needs separate human approval.
