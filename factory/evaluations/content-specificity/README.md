# Content specificity gate

For Production, Creative and Revenue outputs, reject generic praise, repeated stock structures and unsupported claims. The evaluator must require the actual product, audience, evidence and next action. Failures return to the worker with concrete examples.

This gate is evaluation-only. It does not authorize rewriting owner copy. Public hero/gallery words remain subject to the owner's exact review.
