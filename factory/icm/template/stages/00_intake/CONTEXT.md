# Stage 00 — Intake

## Inputs

- User request and available source material.
- Layer 3: `../../_config/mission.md`.
- Existing repository, deployment, customer, and commercial evidence when brownfield.

## Process

Record MODE, OUTCOME, TARGET, CONSTRAINTS, PROOF, and COMMERCIAL VALUE. Capture the current baseline without changing product code. Mark unavailable evidence instead of guessing.

## Outputs

- `project-contract.md` -> `output/`
- `baseline.md` -> `output/`
- `plain-language-summary.md` -> `output/`

## Human gate

The human confirms the actual outcome, audience, constraints, and what would count as proof.

## Plain-language proof

Explain the project like a job ticket: what is broken or missing, who it affects, what must stay safe, and how we will know the work helped.
