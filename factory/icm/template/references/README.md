# Project references

Place stable source material here only when it applies across multiple runs or stages: approved research, policy documents, domain standards, design systems, data definitions, or owner-approved source documents.

Do not put secrets, temporary drafts, or current-run outputs here. Current work belongs in the relevant stage `output/` directory.

When this folder grows, add a `CONTEXT.md` router that tells agents which reference files apply to which stage. Do not load the whole collection by default.
