# Sources and pins

The unified source discovery registry is `skills/workflows/registry.json` (22 optional/canonical/reference/project-only/quarantined entries). These are links and invocation hints, not vendored implementations, verified licenses, or automatic permissions to execute. Before using an external capability, verify current upstream SHA, license/terms, security and distribution rights, then record the checked pin here or in `docs/governance/SOURCE-PROVENANCE-LEDGER.md`. Quarantined and unavailable entries must never auto-run.

- In-repo skills: `skills/<name>/SKILL.md` in this repository.
- External: Matt Pocock skills, https://github.com/mattpocock/skills, tag v1.2.3, commit 6acc160e4e0cd062dbbbd7a1b26ae92855edf07e, MIT license. Reference only. Install separately if wanted; nothing here copies its text.
- Cook: https://github.com/Leonxlnx/cook, commit b23cac6fd9439dfddcab61b14808e7bf72549b46, MIT license. Vendored at `skills/cook/` with its LICENSE; provenance and house guardrails in `skills/cook/PROVENANCE.md`. Referenced by the web-design workflow.
- Design reference sources for the web-design workflow (listed in `w5-web-design/design-references.md`, not vendored): Inspo https://github.com/Nutlope/inspo (commit 022f80977c1e, MIT, free), Awwwards MCP https://github.com/INSANE0777/Awwwards-mcp (commit 0560b94e646d, MIT, free; personal/non-commercial note on its live-audit tools), Agent Browser https://github.com/vercel-labs/agent-browser (commit b06e2533ba9b, Apache-2.0, free). All verified 2026-11-16; installs stay outside this repo.
- "bring your own": a step with no skill in this repo. Add one through a reviewed pull request.

- Automatic PR code-review action: `alibaba/open-code-review` at commit `d30f93864e9c682d27c7fb2d03ae112dca966c32` (reviewed 2026-11-17), CLI npm version `1.13.11`, official composite action in `.github/workflows/vibe-code-review.yml`. This replaces a missing reusable workflow reference. Model calls require owner-set `VIBE_OCR_REVIEW_ENABLED=true`, approved endpoint/model/token and protocol, with a 12,000-token cap. This does NOT constitute a second-model Council receipt or autonomous SHIP approval. Reassess action SHA and npm version on update.
