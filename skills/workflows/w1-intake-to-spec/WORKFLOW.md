# Intake to spec

Load when: a request is fuzzy, new, or big; before any build.
Input: a request or idea. Output: a spec with acceptance checks, then tickets.
Load order: this file only. Open a step's source only when you reach that step.

## Steps

1. Interview, one decision-changing question at a time. Source: repo: skills/grill.
2. Sharpen terms and record decisions. Source: external: grill-with-docs, domain-modeling. external: mattpocock/skills @ v1.2.3 (MIT), reference only
3. Bounded edge-case pass (money, identity, data, retries). Source: bring your own.
4. Write the spec. Source: external: to-spec. external: mattpocock/skills @ v1.2.3 (MIT), reference only
5. Break into tickets; huge jobs become a decision map. Source: external: to-tickets, wayfinder. external: mattpocock/skills @ v1.2.3 (MIT), reference only

## Gate

Stop when the next build step is clear enough to spec.
