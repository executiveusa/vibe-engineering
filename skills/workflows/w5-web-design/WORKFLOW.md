# Web design

Load when: any website, app, or brand surface is built or changed.
Input: a brief and existing context. Output: a distinct, verified surface.
Load order: this file only. Open a step's source only when you reach that step.

## Steps

1. Optional: if the brief names no stack or design system, consider one library from the registry and record the choice; otherwise skip. Source: design-libraries.md (this folder). Reference screens and videos come from design-references.md (this folder); strong references with a short prompt beat a long prompt. When the job specifically needs award-level visual DNA, evidence-based motion study, or an Awwwards comparator, select **Awwwards MCP** from design-references.md as one optional research tool (compact search → details → cited brief; browser capture/verification only when authorized). Do not preload Inspo, Awwwards and every visual library at once, and do not install or scrape by default.
2. Optional: the surface must hold up next to reference screens or video (a redesign measured against examples, not a fresh look). Source: repo: skills/cook. Cook runs the build-compare-critique loop with a numeric bar and zero-context critics. Binding: read skills/cook/PROVENANCE.md before following the skill; its house guardrails override the skill's own defaults wherever they conflict. Upstream's unattended 8-40h runs, its ask-nothing-after-intake rule and its 8h demo floor do not apply here: a run needs an explicit time cap and usage budget in the brief, no paid calls or top-ups just to run it, the owner-approval gate before final render is mandatory, and publishing any output needs the owner's yes. For an ordinary build, skip this step.
3. Keep look distinct across projects, hold shared quality. Source: repo: skills/visual-independence-governor.
4. Taste audit (audit-only by default). Source: repo: skills/icm-awwwards-taste-gauntlet-audit.
5. Mobile, motion, accessibility, deploy gate. Source: repo: skills/mobile-first-site-proof.

## Gate

Audit first; repair only with a recorded decision.
