# Preserve Standards. Forget Style.

Permanent design law:

> **Preserve standards. Forget style. Every brand earns its own world.**

## Preserve globally

Reuse quality and engineering standards freely:

- usability and low cognitive friction;
- ADHD-friendly clarity;
- accessibility;
- craftsmanship and reduction;
- responsive behavior;
- Steve Krug clarity principles;
- Collins-level rigor;
- Apple-level polish;
- Awwwards-level ambition where appropriate;
- Impeccable / anti-slop editing;
- performance;
- verification;
- hierarchy;
- recovery and human control;
- reusable engineering, architecture, component, testing, deployment, accessibility, and workflow patterns.

These are standards, not an aesthetic.

## Never inherit globally

Do not treat any prior project's visual identity as a default.

Never globally default to:

- white or cream backgrounds;
- editorial minimalism;
- oversized whitespace;
- giant headlines;
- serif/sans pairings;
- Inter;
- Geist;
- Space Grotesk;
- split heroes;
- muted palettes;
- thin rules;
- rounded cards;
- magazine grids;
- generic centered SaaS heroes;
- bento grids;
- glassmorphism;
- luxury-serif styling;
- any recurring color, font, layout, component, motion, or image treatment merely because it worked elsewhere.

A previously successful style is evidence that it worked for that brand, not permission to reuse it.

## Brand-world gate

Before material visual design begins, define and persist:

1. **Visual World** — what kind of place, object, scene, medium, or cultural environment this brand visually inhabits.
2. **Emotional Target** — what the user should feel and why that feeling supports the product outcome.
3. **Cultural Sources** — relevant geography, communities, history, subcultures, industries, materials, artifacts, rituals, references, and visual traditions.
4. **Typography** — type behavior, provenance, personality, scale, rhythm, and why it belongs here.
5. **Color Behavior** — not just a palette; define contrast, saturation, temperature, surface use, signaling, and environmental logic.
6. **Density** — sparse, layered, compact, immersive, utilitarian, expressive, or another justified level.
7. **Composition** — grid, rhythm, alignment, framing, asymmetry/symmetry, depth, and spatial behavior.
8. **Image Language** — photography, illustration, 3D, documentary, archival, UGC, collage, texture, diagrams, or another intentional image system.
9. **Motion Language** — pacing, transitions, choreography, physical metaphor, interaction feedback, and reduced-motion behavior.
10. **Anti-References** — explicit visual territories, tropes, brands, prior portfolio projects, and model defaults this project must not resemble.

Do not enter visual BUILD until this gate is specific enough to distinguish the project from the rest of the portfolio.

## Derivation rule

Every unrelated project must derive its appearance from its own:

- audience;
- culture;
- geography;
- industry;
- history;
- brand personality;
- product behavior;
- emotional target;
- imagery;
- physical/material context;
- competitive environment;
- trust requirements;
- interaction model.

Consistency belongs **inside a brand**, not across unrelated brands.

## Portfolio collision test

Before approving a new visual direction, compare it against the existing GitHub / Netlify / Vercel portfolio.

Ask:

- Does this look recognizably like another project before reading the copy?
- Would swapping logo, colors, photos, and text make the two projects interchangeable?
- Are the same typography, hero structure, card language, whitespace rhythm, motion, or grid recurring without project-specific justification?
- Is the design merely a prior house aesthetic wearing new content?

If yes, reject the direction and return to the Brand-world gate.

A new logo, palette, or imagery set does not make a duplicated composition a new design.

## ADHD-friendly rule

ADHD-friendly means reducing cognitive friction:

- clear priorities;
- understandable states;
- strong information scent;
- short confident paths;
- progressive disclosure;
- visible next actions;
- recoverability;
- reduced memory burden.

It does **not** require minimalism, large whitespace, pale colors, few elements, or low visual energy.

A dense interface can be ADHD-friendly if hierarchy and interaction are excellent. A sparse interface can be cognitively difficult if meaning is hidden.

## Benchmark rule

COLLINS, Apple, Awwwards, Impeccable, Steve Krug, and similar references are quality benchmarks, never visual templates.

Extract:

- rigor;
- editing quality;
- hierarchy;
- pacing;
- interaction quality;
- execution discipline;
- coherence;
- accessibility;
- trust;
- technical polish.

Do not copy their surface identity.

## Engineering reuse rule

Reuse engineering patterns freely when they improve reliability, accessibility, performance, maintainability, ownership, or speed.

Examples:

- auth patterns;
- routing;
- form validation;
- data contracts;
- accessibility primitives;
- responsive utilities;
- observability;
- tests;
- CI/CD;
- rollback;
- component behavior.

Do not let engineering reuse silently import unrelated brand appearance.

Separate:

```text
shared behavior/system
        ≠
shared visual identity
```

## Review gate

For material design work, Council/Taste review must explicitly answer:

1. What visual decisions are uniquely justified by this brand?
2. Which decisions came from project evidence rather than model habit?
3. Which portfolio projects were compared?
4. What visual collisions were found and removed?
5. Could this design be mistaken for another project with different copy?
6. Does ADHD-friendly behavior reduce friction without forcing minimalism?
7. Are reference brands used as quality mechanisms rather than copied surfaces?

If the design is a portfolio lookalike, Judge must return `HOLD`.

## Proof

Visual originality is not proven by saying the design is different.

Proof may include:

- side-by-side portfolio screenshots;
- typography and layout comparison;
- composition maps;
- color-behavior comparison;
- image-language comparison;
- interaction/motion comparison;
- named anti-references;
- independent taste review.

## Final law

**Preserve standards. Forget style. Every brand earns its own world.**
