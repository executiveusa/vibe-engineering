# Grill

Read the repo first. Resolve the repository's configured context location before writing project language. Ask one decision-changing question at a time. Record settled project terms in that configured context file. Create or update `CONTEXT.md` only when the repository or owner selected it. Record only consequential hard-to-reverse trade-offs as ADRs. Stop when the next build step is clear enough to spec.
