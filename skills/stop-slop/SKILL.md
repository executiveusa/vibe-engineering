# Stop Slop

Check whether the work actually answers the user. Remove generic AI filler, inflated claims, fake certainty, repeated doctrine, and default AI/SaaS patterns that ignore the project's taste. Check wiring, mobile, accessibility, empty/error states, ownership, and proof. Never accept a confident done claim without evidence.
