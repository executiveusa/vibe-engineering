# Source map and attribution

This skill is an original synthesis. It does not vendor third-party repository code. External projects are references for patterns and routing decisions.

## Control, loops, graphs

- LoopX — https://github.com/huangruiteng/loopx — long-horizon durable control state, objectives/gates/todos/evidence/quota, bounded turns, human judgment.
- Pydantic AI — https://github.com/pydantic/pydantic-ai — typed agents, structured outputs, capabilities, durable execution, Evals, typed graph workflows.
- Apache Burr — https://github.com/apache/burr — explicit state machines, persistence, replay/telemetry, human feedback.
- PocketFlow — https://github.com/The-Pocket/PocketFlow — minimal graph primitive; useful when a tiny understandable graph is enough.
- DSPy — https://github.com/stanfordnlp/dspy — metric-driven optimization of LM programs rather than hand-tuned prompts.
- Graph Engineering — https://github.com/codejunkie99/graph-engineering — task topology, fake-edge deletion, diamond fan-out/verifier/merge, human gate; knowledge-graph pipeline when relationships are the data.
- GraphARC — https://github.com/CodeGraphContext/GraphARC — deterministic pre-execution graph admission, budgets, declared writes, replayable trace.
- Reddit synthesis supplied by owner — https://www.reddit.com/r/WebAfterAI/comments/1vi4ups/5_opensource_repos_that_do_the_loopandgraph/

## Completion, implementation, quality

- Unlazy — https://github.com/Leonxlnx/unlazy — acceptance ledger, runnable gates, re-verification, evidence before completion.
- Ponytail — https://github.com/DietrichGebert/ponytail — YAGNI/reuse/native/stdlib/minimum-code ladder without cutting safety/accessibility.
- Humanizer — https://github.com/blader/humanizer — remove AI-writing patterns while preserving facts and writer voice.
- Ralphy — https://github.com/michaelshimeles/ralphy — PRD/task execution across coding harnesses, isolated parallel worktrees/sandboxes, browser checks.
- Gauntlet Loop — https://github.com/robonuggets/gauntlet-loop — named real bar, fresh critic, blind comparison, repeat until the work wins. Technique attributed by that repo to Matt Shumer; repository license states CC BY 4.0.
- Claude SEO — https://github.com/AgriciDaniel/claude-seo — specialist SEO/GEO/technical/content audit routing with falsifiable recommendations.
- Emil Kowalski Skills — https://github.com/emilkowalski/skills — interaction, animation, Apple-inspired behavior, UI-library selection, animation review.
