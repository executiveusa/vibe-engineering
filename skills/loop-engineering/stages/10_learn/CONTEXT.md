# 10_learn — convert the run into reusable intelligence

One job: preserve verified learning without bloating future context.

## Inputs
- Working: `RECEIPT.md`, `GAUNTLET.md`, `VERIFY.md`, production evidence

## Process
1. Record what the bar exposed, what failed, what fixed it, and which gates caught real issues.
2. Promote only stable reusable rules into `_shared/`; keep project-specific facts in the run/project.
3. Update templates only when the same pattern is likely to recur.
4. Record follow-up opportunities, then classify them. Do not automatically start another workstream.
5. Archive stale intermediate artifacts only after receipts/evidence remain navigable.

## Outputs
- `LEARNINGS.md`
- Optional small updates to shared references/templates
- Final `RECEIPT.md` fields: DECISION, CHANGES, PROOF, STATUS, COMMERCIAL IMPACT, RISKS, ROLLBACK, NEXT, HUMAN APPROVAL

## Human check
Confirm the single next action if another workstream is proposed; otherwise the run closes.
