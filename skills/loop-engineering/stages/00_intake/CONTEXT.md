# 00_intake — establish the control contract

One job: orient, inspect what is already knowable, ask only the missing high-leverage questions, and secure a real bar.

## Inputs
- Working: run `STATE.md`, `BAR.md`, `PROJECT-LOCK.md`
- Reference: `_shared/standards/commercial.md`
- Reference: `_shared/standards/bar-and-gauntlet.md`

## Process
1. Determine greenfield vs brownfield. For brownfield, inspect repo/product before asking the owner questions the system can answer itself.
2. Fill what can be proven: outcome candidates, target, constraints, protected assets, current deployment, ownership, classification/workstream.
3. Ask the minimum unresolved questions in one packet. Always resolve the bar first; if absent, propose 2-3 specific comparable bars.
4. Record facts separately from assumptions.
5. Do not build yet.

## Outputs
- Updated `BAR.md`
- Updated `PROJECT-LOCK.md`
- Updated `STATE.md` -> `next_stage: 01_discovery`

## Human check
Choose/approve the bar and correct any wrong project-lock assumptions. This can be one response.
