# Shared library

One job: provide stable references without forcing them into every turn.

## Inputs
- Stage contract naming the needed reference.

## Process
1. Follow `_shared/routing/skill-router.md`.
2. Read only the doctrine/standard needed for the current stage.
3. Prefer original source material when a distilled rule is ambiguous.

## Outputs
- No working output. Shared files are factory configuration.

## Human check
If a source doctrine conflicts with a project-specific owner instruction, record the conflict in the run and ask the owner which rule governs.
