# Commercial doctrine

Use at intake/discovery and whenever scope expands.

- Cash before more code when a sellable offer can be tested without more engineering.
- Classify: `SELL`, `USE`, `MERGE`, `PARK`, or `ARCHIVE`.
- `SELL` requires a realistic path to revenue within 30 days.
- Keep at most three active workstreams: one revenue offer, one shared platform, one bounded experiment. New work states what it replaces.
- Default commercial path: Vibe Audit -> Vibe Rescue Sprint -> Sovereign Launch -> MAXX Operations.
- Stop drift when engineering replaces outreach/proposals/payment, when scope has no customer/deadline/outcome, or when another tool duplicates an existing capability.
