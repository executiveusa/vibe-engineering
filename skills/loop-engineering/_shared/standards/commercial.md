# Commercial and portfolio gate

Record in `PROJECT-LOCK.md`:
- measurable outcome;
- target customer/user/system;
- commercial value: revenue, savings, retention, donations, applications, or validated learning;
- classification: SELL / USE / MERGE / PARK / ARCHIVE;
- if SELL: plausible path to revenue within 30 days;
- which active workstream this occupies: revenue offer / shared platform / bounded experiment;
- if this would create a fourth active workstream, what it replaces.

A technical success that creates no chosen commercial/social/operational value does not automatically justify more engineering.
