# Skill router — activate expertise just in time

Do not preload every skill. Match the current stage and artifact.

| Trigger | Activate/read | Purpose | Do not use when |
|---|---|---|---|
| Greenfield idea / offer uncertainty | owner `SKILL-PROVEN BETTER NEW.txt` | analog research, instinct, proven/better/new, atomic tests | problem and paid demand are already proven |
| Brownfield repo | owner Full-Stack Wiring Audit + `mobile-mission.md` | baseline, canonical state, promise-to-runtime truth | no existing system exists |
| Product/UX scope | `heart-and-soul.md` | subtraction and essential path | purely backend/internal refactor with no UX change |
| Website / product surface | `collins-level.md` | strategy, distinction, content, states, responsive rigor | non-visual backend-only task |
| Landing page / SaaS conversion | owner God-Tier LP source | audience awareness, benefits/proof/CTA copy | not a marketing/conversion page |
| Interaction / motion | Emil Kowalski skills | animation, Apple behavior, library choice | static content with no interaction need |
| Loading/perceived wait | Unlazy principles + runtime evidence | truthful loading, remove fake waiting | no latency state exists |
| Code implementation | Ponytail ladder | reuse, stdlib/native, minimum justified code | never cuts security, validation, accessibility, recovery |
| Repeated task execution | Ralphy or host-native task runner | PRD execution, isolation, worktrees, browser check | one small manual slice is safer/easier |
| Long-horizon multi-day work | LoopX if installed/approved | durable objective/gates/todos/evidence across harness turns | short single-session task |
| Dynamic graph planned by model | GraphARC pattern/runtime | admit before execute, budgets, policy, declared writes, replay | static known task graph |
| Python agent app with typed I/O | Pydantic AI | typed outputs/tools/capabilities/evals/durability | ordinary web app not needing agent runtime |
| Explicit state-machine app | Apache Burr | persisted actions/transitions/replay/telemetry | simple sequential script |
| Tiny custom agent graph | PocketFlow | minimal understandable graph | production requirements justify richer runtime |
| Repeated LM behavior has a metric/dataset | DSPy | optimize prompts/program against measurable metric | one-off prompt or no reliable metric |
| Knowledge domain needs multi-hop relationships | Graph Engineering knowledge-graph lane | ontology -> extraction -> fusion -> serving | table/document retrieval is enough |
| SEO/GEO/technical search work | Claude SEO | specialist, parallel, falsifiable audit | SEO is not in scope |
| Public-facing prose | Humanizer | remove AI-writing patterns without inventing facts | code/data/contracts where rewriting changes semantics |
| Cinematic scroll-film concept selected | owner Scroll-Film Studio | specialist media chain and film verification | do not force cinematic treatment onto ordinary sites |
| Any substantial completion claim | Unlazy gate discipline | acceptance ledger + rerun evidence | never skip because work 'looks done' |
| Final quality comparison | Gauntlet Loop pattern | fresh critic, real bar, blind comparator | no valid bar yet |

Rule: references teach patterns. Do not install or combine frameworks unless the architecture decision in `02_architecture` justifies their cost and ownership impact.
